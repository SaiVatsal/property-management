# Project 28: Property Management System (Belgravia & SoHo)

A luxury real estate asset and tenant portfolio management platform built with React, Vite, TailwindCSS, and Zustand.

## Features
- **Navy & Warm Gold Palette**: Regal prime real estate design (`#0f172a`, `#1e293b`, `#d97706`, `#fbbf24`) with Playfair Display serif address headings.
- **Prime Asset Portfolio**: Track penthouses, townhouses, and lofts with square footage, occupancy status, and annualized cap rates.
- **Rent Roll Management**: Monthly rent collection audit, advance payments, and upcoming due dates.
- **Concierge Work Orders**: Maintenance ticketing with specialized engineering contractor dispatch and resolution sign-offs.
- **Yield & Cap Rate Analytics**: Real-time portfolio capitalization rates, total rent roll, and tenant tenure metrics.

## Getting Started
```bash
npm install
npm run dev
```
